      Accès des familles

      Chaque élève reçoit un code. Le parent crée son compte dans l'espace parents, puis écrit le matricule de son enfant et ce code (une seule fois).

      Données de test

      Remplit l'école avec des élèves, des notes, des présences, des frais, des devoirs, des messages, un horaire et un calendrier inventés, pour essayer l'application. Les classes de test portent « (test) » dans leur nom. Tu pourras tout supprimer d'un seul bouton, sans toucher à tes vraies données.

      Sauvegarde

      Les données restent dans le navigateur de ce téléphone (et dans la base en ligne si tu es connecté). Si tu vides les données du navigateur, tout disparaît. Exporte-les régulièrement.
